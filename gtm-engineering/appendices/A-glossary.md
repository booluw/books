# Appendix A. Glossary

Chapter references in brackets.

| Term | Definition |
|---|---|
| **ABM / ABX** | Account-based marketing / experience: coordinated sales and marketing aimed at a defined list of high-value accounts. [3] |
| **ACV** | Annual contract value. [3] |
| **AE** | Account executive: the salesperson who runs deals to close. [1] |
| **AI SDR** | Software agent that prospects, writes and sends outreach, and books meetings with limited human involvement. [13] |
| **ARR / MRR** | Annual / monthly recurring revenue. [3] |
| **Attribution** | Assigning credit for pipeline or revenue to preceding touches. [15] |
| **BANT / MEDDPICC** | Qualification frameworks. [3] |
| **Bounce (hard / soft)** | Permanent / temporary delivery failure. [11] |
| **Buying committee** | The group of people involved in a B2B purchase decision. [3, 4] |
| **CAC** | Customer acquisition cost. [3] |
| **CAC payback** | Months of gross-margin-adjusted revenue needed to recover CAC. [3] |
| **CAN-SPAM** | US law governing commercial email (opt-out regime). [16] |
| **CASL** | Canada's anti-spam law (consent-based). [16] |
| **Catch-all domain** | A mail domain that accepts all addresses, so mailboxes can't be verified. [7] |
| **Champion** | An internal advocate at a customer or prospect. [7, 8] |
| **Clay** | A GTM data and automation platform that coined "GTM engineering" (2023). [1, 6] |
| **Cohort analysis** | Measuring conversion for a group that entered a stage in the same period. [3, 15] |
| **Cool-down** | A minimum interval before the same account is actioned again. [8] |
| **CRM** | Customer relationship management system (Salesforce, HubSpot…). [5] |
| **Dark funnel** | Buyer influence that leaves no trackable touch (podcasts, communities, word of mouth). [15] |
| **Decay (signal)** | Reduction of a signal's weight over time, often exponential with a half-life. [8] |
| **Deliverability** | The ability to land email in recipients' inboxes. [11] |
| **DKIM** | DomainKeys Identified Mail: cryptographic message signing. [11] |
| **DMARC** | Policy and reporting built on SPF and DKIM, requiring alignment with the From domain. [11] |
| **Enrichment** | Adding attributes to existing records from external sources. [7] |
| **Fit score** | How well an account matches the ICP, independent of timing. [4, 9] |
| **GDPR** | EU General Data Protection Regulation. [16] |
| **GTM** | Go-to-market: how a company finds, reaches, converts and expands customers. [1] |
| **GTM engineer** | A builder of the data, automation and AI systems that generate and convert pipeline. [1] |
| **ICP** | Ideal customer profile: the companies most likely to buy, succeed and expand. [4] |
| **Intent data** | Signals that an account is researching a topic or category. [8] |
| **Lead / Contact / Account** | Person not yet tied to a company (Salesforce Lead) / person at a company / company. [5] |
| **Lead-to-account matching** | Linking incoming person records to existing company accounts. [5] |
| **LIA** | Legitimate interests assessment under GDPR / UK GDPR. [16] |
| **LTV** | Customer lifetime value. [3] |
| **MCP** | Model Context Protocol: standard for AI assistants to use tools and data. [13] |
| **MQL / SQL / SAL** | Marketing qualified / sales qualified / sales accepted lead. [3] |
| **Multithreading** | Engaging several members of a buying committee. [4, 10] |
| **NRR / GRR** | Net / gross revenue retention. [3] |
| **Opportunity** | A tracked potential deal with amount, stage and close date. [3] |
| **Persona** | Description of a buyer role: titles, responsibilities, pains. [4] |
| **Pipeline coverage** | Open pipeline ÷ revenue target. [3] |
| **Pipeline velocity** | (Opportunities × deal size × win rate) ÷ cycle length. [3] |
| **Play** | A repeatable GTM motion with a hypothesis, audience, trigger, message and metrics. [10] |
| **PLG** | Product-led growth: acquisition and expansion driven by product usage. [3, 12] |
| **Postmaster Tools** | Google's sender reputation and compliance dashboard. [11] |
| **PQL / PQA** | Product-qualified lead / account. [12] |
| **PECR** | UK Privacy and Electronic Communications Regulations. [16] |
| **Public Suffix List** | List of domain suffixes (e.g. co.uk) used to find registrable domains. [5] |
| **Reverse ETL** | Syncing modelled warehouse data back into operational tools. [12] |
| **Reverse funnel** | Working backward from a revenue target to required activity. [3] |
| **Reverse-IP** | Mapping website visitor IP addresses to companies. [8] |
| **RevOps** | Revenue operations: unified sales, marketing and CS operations. [1] |
| **Round robin** | Rotating assignment among eligible reps. [9] |
| **Rules of engagement** | Agreed ownership and routing rules between sales teams. [9] |
| **SDR / BDR** | Sales / business development representative: prospects and books meetings. [1] |
| **Sequence / cadence** | Timed multi-step, multichannel outreach. [10] |
| **Signal** | A time-stamped event suggesting changed circumstances or buying interest. [8] |
| **Spam trap** | An address used to identify senders with poor list practices. [11] |
| **Speed to lead** | Time from inbound request to first meaningful response. [9] |
| **SPF** | Sender Policy Framework: DNS list of authorised sending servers (10-lookup limit). [11] |
| **Suppression list** | Addresses, domains or phones that must never be contacted. [16] |
| **TAM / SAM / SOM** | Total / serviceable / obtainable addressable market; in GTM engineering, the concrete list of ICP accounts. [4] |
| **Technographics** | Data about the technologies a company uses. [4, 7] |
| **Tier** | Priority level of an account within the TAM. [4] |
| **Upsert** | Update if exists, else insert, by a key. [6] |
| **Verification (email)** | Checking syntax, domain, MX and mailbox without sending. [7] |
| **Warehouse-native GTM** | Using the data warehouse as the GTM data hub with reverse ETL. [12] |
| **Warmup** | Gradually building a new inbox or domain's sending reputation. [11] |
| **Waterfall enrichment** | Querying providers in sequence until an acceptable result is found. [7] |
| **Win rate** | Closed-won ÷ (closed-won + closed-lost). [3] |
